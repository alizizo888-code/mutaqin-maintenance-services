# مُتقن MUTQAN — خدمات الصيانة

المستودع مخصص لنسخة PHP + MySQL من منصة مُتقن لخدمات الصيانة والمقاولات.

## الحالة

هذا المستودع كان فارغًا عند بدء التجهيز. تمت إضافة ملف README التأسيسي فقط لتكوين الفرع `main`. لم تُرفع حزمة التطبيق بعد.

## البنية المستهدفة

- `index.php` — واجهة العميل
- `backend/config/` — إعدادات قاعدة البيانات المحلية
- `backend/api/` — واجهات الطلبات والأنظمة
- `backend/upload/` — معالجات رفع الصور وملفات الفواتير
- `database/schema.sql` — مخطط MySQL
- `docs/` — التوثيق وتقارير الفحص

قبل التشغيل، انسخ `backend/config/config.local.php.example` إلى `backend/config/config.local.php` وأدخل بيانات MySQL من لوحة Hostinger. لا ترفع كلمات المرور أو الأسرار إلى GitHub.

راجع `README_AR.md` في حزمة التوزيع لتعليمات التثبيت الكاملة.
