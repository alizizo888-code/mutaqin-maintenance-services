# مُتقن MUTQAN — منصة الصيانة (PHP + MySQL)

المستودع يحتوي الآن على بنية مصدرية فعلية: نقطة دخول PHP، واجهات API، إعدادات قاعدة البيانات النموذجية، مخطط SQL، واجهات HTML التجريبية، مواصفات المشروع، ونسخ مرجعية من الملفات المرفوعة.

## بدء التشغيل
1. ارفع الملفات إلى استضافة PHP مثل Hostinger.
2. أنشئ قاعدة MySQL ثم استورد `database/schema.sql` من phpMyAdmin.
3. انسخ `backend/config/config.local.php.example` إلى `backend/config/config.local.php` وضع بيانات قاعدة البيانات الحقيقية.
4. افتح النطاق. إعدادات كلمات المرور المحلية لا تُرفع إلى GitHub.

## المكونات
- `index.php`: واجهة طلب صيانة مبسطة مرتبطة بواجهات API.
- `backend/api/api.php`: CRUD الأساسي للأنظمة الخمسة.
- `backend/api/operations.php`: غرفة العمليات والإسناد.
- `backend/api/invoices.php`: عمليات الفواتير.
- `backend/upload/image-handler.php`: رفع الصور المحلية مع بصمة SHA-256.
- `frontend/prototypes/`: معاينات واجهات العميل وغرفة العمليات والفواتير.
- `docs/`: تقارير ومخططات المشروع.
- `reference/original-uploads/`: الملفات المصدرية الأصلية كما وردت.

## حالة الحزمة الثنائية
لم يتم تخزين ملف ZIP ثنائي كملف داخل GitHub في هذا التحديث؛ تم رفع المصدر المقروء وبنية المشروع نفسها. حزمة ZIP الكاملة ما زالت متاحة في مرفق المحادثة.
